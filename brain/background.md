# Project background

## Why
终端五十年来停留在字符网格模型。TGS 通过扩展转义序列，让终端成为轻量级图形平台。

## Goals
- 应用通过字节流构建图形界面，不需要图形库
- 终端管窗口，应用管布局
- 支持 SSH/PTY/管道传输
- 20+ 控件类型，7+ URI scheme
- Layer 0 MVP 可运行

## Non-goals
- 不取代 X11/Wayland
- 不取代浏览器
- 不取代 Qt/GTK

## Target user
开发、运维、服务器管理 — 终端重度用户
